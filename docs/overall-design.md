## 请负责人定

（以下四项负责人已于 2026-11-18 通过。）

1. **两级沙盘，中间是切换。** 代价是：站与站之间路上的山川（三峡、大庾岭、琼州海峡）只在全程沙盘上看得到，那里的山很矮，看不出峡谷和关口。要让人看清这些地方，得另做一座路段的沙盘（比如瞿塘峡），算多一座的工作量。先不做；写到眉山、惠州和儋州这两站时再请负责人定。
2. **进一站先看来路**（可以跳过）。
3. **楷体换成开源字体。** 样张里的楷体是 Windows 自带的，不能随网站发，平板和手机上也没有。换成开源的霞鹜文楷，笔画略圆、略轻，和样张不完全一样。对比图见 `spikes/art-direction/b/shots/08-font-compare.jpg`。2026-11-24 起楷体只用在沙盘的题签和印上，页面的标题和按钮用黑体。
4. **考证怎么做。** 沙盘上的考证由制作方查公开的史料、方志和考古报告，写明出处；查不到的一律标成示意。没有历史地理专业的人审校。负责人如果想请懂行的人把关，就在每座沙盘定稿前加这一关。

## 一句话

选一位历史名人，以“我”的身份，沿着他一生走过的路一站一站读下去，在每个地方看见当时的时代、山川、风物和技艺。

## 设计原则

1. **是学习网站，不是游戏。** 没有分数、关卡、任务。
2. **用户就是他本人。** 全程用“我”来讲，只讲他当时看到和知道的事。
3. **内容为主。** 正文由人精心编写，AI 只在旁边答疑。
4. **自然。** 不刻意解释原因，把背景和处境写清楚，读的人自己明白。每位人物独立成篇，不刻意互相连接。不刻意求新奇。
5. **全年龄。** 正文孩子能独立读完，想深入的人点开小注。
6. **趣味来自具体。** 住哪里、吃什么、路多远、钱够不够，这些让人读得进去，不靠游戏机制。
7. **画面要让人想看。**（新）每个地方是一座做出来的立体沙盘，用他那个时代的颜色和题字。

## 网站结构

只有三层页面：

```
首页：挑选一位人物
 └─ 人物页：他是谁 + 一生轨迹的全程沙盘 + 各站目录
     └─ 站点页（沿轨迹排列，约 6–10 站）
         ├─ 沙盘：这一站的场景
         ├─ 正文：“我”的自述
         ├─ 可点开：小注、原文、图片
         └─ 问讲解员（AI 答疑）
```

- **首页**：人物卡片，每张写名字、时代、一句话介绍，按时代排列。旁边摆一座沙盘。
- **人物页**：一座画着他全部轨迹的全程沙盘，站点既是沙盘上的点，也按先后列成目录。
- **站点页**：沙盘是页面的主视觉，占大部分面积；正文是旁边的一栏，窄屏时沙盘在上。页尾是“上一站”“下一站”。

## 画面（新）

- **立体沙盘。** 像博物馆里的沙盘：地形做成立体模型，城、楼、亭、桥、船、田、树是摆在上面的小模型，整座沙盘装在木框里。
- **设色。** 苏轼这一位用宋代青绿山水的颜色：平地是茶色和赭石，山脚赭石、山坡石绿、山顶石青，水是淡花青，低处有薄雾。沙盘上的强调色只有印章红一种。
- **题签。** 地名写在竖排的楷体题签上，下面一方红印；水名的字用靛青。
- **页面。** 分两层。沙盘，和摆在沙盘上的题签、印，是人物自己的一层，跟着人物的时代走。沙盘以外的——首页、正文那一栏、按钮、面板、沙盘栏上下的按钮和题记——是哪位人物都共用的框架，样子是中性的：近乎白的底，深灰的字，一种墨蓝做记号；标题、标签、按钮用黑体，成句的话用宋体；没有纸的纹理，没有印，没有竖排的字。（2026-11-24 改的。原来是“左边一页宣纸，右边绢底，标题、小节名用楷体”。）宽屏上正文在左，沙盘在右。字体随网站一起发，各种设备上看到的是同一种字（见“请负责人定”第 3 条）。
- **每位人物按自己的时代另配颜色和题字**，沙盘的做法不变，框架也不变。做到新人物时，这位人物的颜色和题字由制作方定，做完拿图告诉负责人（`decisions.md` 第 49 条）。

样张见 `spikes/art-direction/b/shots/`。

## 沙盘（原“地图”，改）

- **一套沙盘程序，所有人物共用。** 每位人物提供自己的数据：轨迹、站点、古今地名、每座沙盘上摆什么、每一小节的镜头。零件库里还没有的东西（比如海船、石桥）和新时代的颜色、题字要添进程序，添了以后别的人物也能用。
- **全程三维，地形以真实高程为底。** 山的位置和形状按今天的高程数据立起来。为了看得清会做几样修整，每一样都写在沙盘旁边：山的高度夸大；平地抹平；个别地方按正文垫高或挖低（如徐州城南的高地）；河画得比实际宽。
- **两级沙盘。**
  - 全程沙盘（人物页）：把他一生走过的范围做成一座大沙盘，山脉、大河、海岸是立体的，轨迹画在上面，每一站是上面的一个点。苏轼这座东西约两千公里，比站点沙盘大一百多倍，所以山立得不高，主要靠颜色分出山地和平原。
  - 站点沙盘（每站一座）：这一站所在的那块地方，大小按各站的需要定（徐州那座东西约 12 公里、南北约 10 公里），上面摆正文提到的东西。
- **进一站，先看来路。** 先在全程沙盘上看一眼从上一站到这一站的那段路，再换到这一站自己的沙盘。可以跳过。
- **不止一个地方的站。** 有的站讲的是一段路或两个地方（从眉山出川；惠州和儋州相隔六百多公里）：路在全程沙盘上讲，两个地方各做一座沙盘。正文提到、却在沙盘之外的远处（徐州的白土镇），在沙盘边上指出方向和距离。
- **同一个地方去两次**（杭州），用同一座沙盘，摆成前后两个时期的样子。
- **镜头跟着正文走。** 一小节一个镜头，读到哪一节，镜头移到哪里。有的小节沙盘本身会变：徐州的水涨上来、退下去；后来才盖的黄楼，到那一节才出现。
- **沙盘可以比正文先做好**（2026-11-24 加的；眉州是头一座）。这样的站没有正文带着镜头走：沙盘上看三到六处，每一处有名字、时间和一句题记；文字栏里是一句“这一站的正文还没写”和一张单子“沙盘上看的几处”，按哪一行，沙盘就换到哪一处。正文写好以后，镜头照旧跟着正文走。
- **用户可以自己转动、倾斜、缩放沙盘**，旁边有“回到这一节”的按钮（沙盘先做好、正文还没写的站上写“回到这一处”）；可以收起正文只看沙盘。
- **题签写当时的地名**，可切换成今天的地名。
- **沙盘上只摆当时有的东西**，不画现代道路和城市。不做小人、车马这类活动的东西。

## 分清真的和示意的（新）

文字可以写“大约”“据说”，沙盘却一定会把城墙、河道画在某个确定的位置，所以要另外交代清楚。摆上沙盘的东西分五类：

| 类别 | 是什么 | 例子 |
|---|---|---|
| 真的 | 山的位置和形状，来自今天的高程数据 | 云龙山 |
| 今天的位置 | 今天还找得到的地点。是今天的遗址或重建处，不一定是当时的原处 | 今天的黄楼、今天山顶上的放鹤亭（都不在当年的位置） |
| 按史料摆的 | 正文或史料说了在哪，细节说不准 | 东门上的黄楼、东南的堤、云龙山西坡上的放鹤亭 |
| 示意的 | 没有可靠依据 | 城墙的范围、河道的线位和宽窄、楼的样子、大水的水位 |
| 点缀 | 只为让人看出这是城、是村、是岸，不代表当时真有这一座 | 民居、田、树、成排的船 |

- **平地和水边不能当作当时的原样。** 用的是今天的地面，而且修整过。徐州一带后来被黄河的泥沙垫高了；当时的汴水、泗水后来被黄河占了几百年，今天市区的故黄河大致是它留下的旧河道，两条河原来确切的走向和宽窄已经说不准。黄州的赤壁当时就在江边，今天离江堤有几百米，离江水有两公里多。
- **每座沙盘旁边有一句说明**：哪些是示意，地形修整了哪里，山高夸大了多少，模型和河比实际放大了。全程沙盘上低山和高山夸大得不一样时，写出范围。
- **摆上沙盘的每一样东西都归到上面的一类并写明依据**，和正文的“凭据”同样对待。点缀可以成片登记。
- **今天才有的地貌不照今天的画。** 全程沙盘上，黄河下游、淮河入海的河道、汴河和苏北的海岸，当时都和今天不一样，黄河下游在他这几十年里自己还改过几次道。这些只能按史料画出大致走向，一律标成示意。
- **一座沙盘上如果绝大部分是示意**（汴京：地是平的，宋代的城埋在今天的地面下），动手前先请负责人定做不做、怎么做。

## 一站里有什么

| 部分 | 内容 |
|---|---|
| 抬头 | 站名、年份、地点（古今地名）、他当时的年纪 |
| 正文 | 第一人称，约一千字，分几小节 |
| 小注 | 点开才出现，分历史、地理、人文、科学四类，只注正文里出现的东西 |
| 原文与图片 | 他本人的诗文书信（附白话）、文物、手迹、实地照片 |
| 沙盘 | 这一站的场景：来路，这块地方的地形，正文提到的地点；一小节一个镜头 |
| 凭据 | 哪些话出自他本人或史书，哪些是编写时补的；沙盘上的东西各属哪一类 |

正文还没写、沙盘先做好的站（2026-11-24 加的；眉州）：有抬头、沙盘和凭据里“沙盘上的东西”一栏；正文的位置上是一句话和那张单子“沙盘上看的几处”；没有小注、原文与图片。

## 讲解员（AI 答疑）

- 站在故事之外，用第三人称回答，不扮演人物。
- 以站内已编写的内容为依据，答不了就说不知道。
- 主要用途：解释字词，换一种说法讲给孩子听，回答“后来怎样了”。

## 人物与制作顺序

1. 先做一位，把整套骨架走通：苏轼。
2. 再做一位不同类型的，验证骨架通用：达尔文或徐霞客。
3. 然后扩到首批约十位。

（新）每一站要做一座沙盘，比原来只给地图定一个镜头位置费工得多。先把苏轼的两座做出来，量一量一座实际要多少工夫，再定后面的节奏；首批约十位的进度现在定不下来。

（新）换成沙盘以后，第二位的两个人选难度不一样：徐霞客的全程沙盘和苏轼的做法相同，只是范围更大；达尔文绕了地球一圈，全程沙盘要做成世界范围的，山几乎立不起来，要另出样张。选第二位时把这一点算进去。

## 重做的范围（原“原型的范围”，改）

动手之前先做两件小事，都不改画面的做法：

- 把现在的徐州样张原样发到网上，负责人用平板和手机打开，看流畅不流畅（发布由负责人决定）。
- 出一张全程沙盘的样张。它的样子还没有人见过；不通过的话，“两级沙盘”回到这份设计重新商量。

然后重做：

- 首页：中性的框架，两三张人物卡片，只有苏轼可以点进去，旁边一座沙盘。
- 苏轼人物页：全程沙盘加八站目录。
- 两站完整：徐州和黄州（正文已写好），各一座沙盘，镜头逐节跟着正文；徐州的水会涨落，黄州的大江有水落、平时、高水三种水位。
  - 徐州从样张变成正式的一站时，城墙、河道、堤、水位、黄楼的位置先逐项考证或标成示意，补上样张里没有的两节镜头。
  - 黄州有三小节写的是夜里的事（赤壁的两个夜晚、承天寺的一夜）。设色的夜景先出了样张，再做上去：沙盘上不画月亮，光从那一夜月亮的方向来；夜色在真的平板上看着怎样，还要在真机上看。
- 其余六站：在全程沙盘和目录里有位置，标“还没写”。
  - 其中眉州（头一站）2026-11-24 有了自己的沙盘，看四处：整座沙盘、纱縠行的家、正月上蟆颐山、老翁泉。正文还没写，目录里仍标“还没写”。别的五站的沙盘一座一座接着做。
- 讲解员仍然只有界面，答疑功能随后接入。
- 验证：沙盘在平板上是否流畅，题签是否清楚，字体是否显示正确。（2026-11-19 起只考虑平板和电脑，不考虑手机，见 `decisions.md` 第 22 条。）

## 暂不做
